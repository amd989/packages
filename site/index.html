packages.alejandro.md

Signed APT repository for my projects. One source, one key.

Setup

curl -fsSL @@BASE_URL@@/setup.sh | sudo sh

Then install whatever you came for:

sudo apt install mariner3d

Manual setup

If you would rather not pipe a script into a shell:

sudo curl -fsSL @@BASE_URL@@/gpg.key \
  -o /usr/share/keyrings/alejandro-md.asc

sudo tee /etc/apt/sources.list.d/alejandro-md.sources >/dev/null <<'EOF'
Types: deb
URIs: @@BASE_URL@@/deb
Suites: bookworm
Components: main
Signed-By: /usr/share/keyrings/alejandro-md.asc
EOF

sudo apt update

Replace bookworm with trixie on a trixie system.
